# Library Automation Tool

A Python-based Library Automation Tool developed as part of a virtual Python development internship.

## Features

- Add new books to the library
- View available books
- Borrow books
- Return books
- View borrowed books
- Prevent duplicate books
- Validate user input
- Handle invalid menu choices
- Handle unexpected errors

## Technologies Used

- Python
- Lists
- Dictionaries
- Functions
- Loops
- Conditional statements
- Exception handling

## How to Run

1. Download or clone this repository.
2. Open `library.py` using Python IDLE or any Python editor.
3. Run the program.
4. Select an option from the library menu.
5. Follow the instructions displayed on the screen.

## Library Workflow

1. Add a book by entering its title and author.
2. View books that are currently available.
3. Borrow an available book.
4. Return a borrowed book.
5. View currently borrowed books.
6. Exit the application.

## Error Handling

The application validates user input and handles errors such as:

- Empty book details
- Duplicate books
- Borrowing an already borrowed book
- Returning a book that is not borrowed
- Invalid menu choices
- Unexpected program errors

## Project Purpose

This project demonstrates practical Python programming concepts including data processing, input validation, functions, lists, dictionaries, loops, and error handling.
